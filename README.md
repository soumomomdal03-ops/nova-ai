# NOVA AI — Phase 1 Complete Android Project

## What Is Included in Phase 1
- **Native Kotlin + Jetpack Compose** (Android 8.0+ / API 26+, MVVM + Clean Architecture)
- **Premium Black + Emerald Green Glassmorphism UI** with Dark Mode & Light Mode toggle
- **Animated Glowing AI Orb** on Dashboard & Audio-Reactive Plasma Orb in Voice Assistant
- **Full Phase 1 Screens**: Splash Screen, 3-step Onboarding, Sign In / Register (local session), Main Dashboard, AI Chat with Multi-Step Task Planner, Voice Assistant, Ecosystem Hub, Module Architecture Details, AI Settings & Privacy
- **Real Android Speech-to-Text (`SpeechRecognizer`) & Text-to-Speech (`TextToSpeech`)** supporting English, Hindi, and Hinglish, Male/Female AI voices, and Continuous Conversation Mode
- **Jetpack DataStore** persistent user preferences (theme, language, voice gender, approval policy)

## Easy Setup Steps in Android Studio (No Coding Needed)
1. **Unzip** `NOVA_AI_Phase1_Android.zip` to a folder on your PC (for example `C:\Projects\NOVA_AI_Phase1`).
2. Open **Android Studio** (Koala / Ladybug / Meerkat or newer with JDK 17).
3. Click **Open** and select the `NOVA_AI_Phase1` folder.
4. Wait 1–3 minutes for **Gradle Sync** to download dependencies automatically.
5. Connect your Android phone (with USB Debugging ON) or start an Android Emulator (Android 8.0+).
6. Click the green **Run ▶** button to install and launch **NOVA AI**.
7. Tap the **Voice Orb** and allow **Microphone permission** when prompted to test live Hindi/English/Hinglish voice chat.
